# 公开冻结留出集 v1

本目录是新编写的虚构「折光资料社」资料：12 份文档，32 条查询，直接查询、
改述、跨文档多证据和无答案各 8 条。全部组织、项目、代号与规则均为原创虚构，
不描述真实机构，不包含用户资料、真实人员或第三方网页原文。

它与 `rag_general` 的 16 份文档和 60 条查询分别维护，文件名、完整文档摘要与
查询文本互斥。32 条查询中 24 条有答案、8 条资料不足；无答案的参考说明不进入
索引，不能因为返回了相似片段就记作答案正确。多证据查询每条都需要至少两份
不同文档，完整证据率仍需逐个 gold 条件核对。

文档、查询和 gold 由同一 AI 作者在本轮排序实验前编写并冻结；没有独立人标、
盲审或真实用户任务。**这是公开冻结的合成留出集，不是独立作者的真实测试集。**
全文对开发者可见，不能宣称防止所有信息泄漏或代表生产泛化；实验结果用于暴露
固定方案在新材料上的局限，不根据结果回改这版样本、标签或方案。

`manifest.json` 沿用现有公开基准结构，逐文件保存 SHA-256。
`freeze.json` 额外锁定清单、查询、文档及本说明的字节摘要；加载器也核对开发集
的文档与查询摘要，避免两套材料后来互相混入。新增版本需要显式另行冻结，
不能通过重写本版本的摘要文件掩盖实验后的改动。摘要提供一致性证据，不是签名
或不可篡改时间戳。

仅清单内的 Markdown 进入检索。`eval_set.json`、参考答案与冻结文件只用于校验，
不参与索引，也不读取 `.env`、`data/notes` 或额外知识库目录。服务默认语料仍为空，
本目录不会被评测以外的入口自动加载。
