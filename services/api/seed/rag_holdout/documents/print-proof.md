## 霁光第六期校样截止
折光资料社的霁光第六期在周一十二点停止接收本期文字修改，之后的新增内容登记到下一期。停止接收修改与印刷完成是不同节点，不据此断言纸张已经出库。校样角色代号为风页，不对应真实姓名。截止前比较正文、页码与图注，缺少图注的页面保留待确认标记，不从其他期刊复制说明，也不自行猜测图片的拍摄对象。

## 霁光双面样张复核
霁光第六期正式整理前先做双面两张样张，核对正反页次和边缘裁切位置。复核记录分别说明页次是否连续、图注是否贴近对应图片，不能只写“样张正常”。发现页码错误时标记问题页后重新核对，不以改变装订顺序掩盖正文错页。样张复核规则仅是虚构编辑流程，不提供真实印厂联系方式、商业报价、纸张采购单或承印单位资料。

## 霁光文字更正记录
已进入下一期的更正条目保留旧文字、建议新文字和更正理由，审核角色确认后再排入新校样。更正登记不会自动替换已经分发的纸质材料，读者看到旧版时应明确它的期次。演练中使用公开虚构短文，不收集真实作者合同或个人署名。所有代号只帮助区分角色，不能据此补写负责人身份、联系电话或真实组织的职务关系。
