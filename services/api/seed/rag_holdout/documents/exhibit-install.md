## 回声窗搭建窗口
折光资料社的回声窗展示在周四十四点开始搭建，联络角色先核对公开展件清单与展示面板编号。搭建开始不代表展览正式开放，开放日期另行记录。需要房间或便携物件时分别走预约与借用流程，不能用展件清单替代场地确认。这是虚构展示项目，没有真实施工地址、承包商身份或面向公众的活动公告，不据此安排现实中的参观行程。

## 回声窗框架复核
框架完成后记录横杆编号、锁点照片和两名复核角色代号，三类记录齐全才标注框架已复核。只拍一张整体照片不能代替锁点照片，也不能代替第二位角色的核对。框架复核与屏幕片段检查分开记，画面能够播放并不说明支架记录已经齐全。复核规则只用于公开演练，不作为真实结构安全标准或真实场地的工程建议。

## 回声窗撤展分工
撤展时先按展件编号归还面板和框架，再核对已登记的便携物件借用单。角色代号说明由谁整理和谁复核，但没有个人联系方式。出现编号不一致时保留原标签并登记差异，不用新编号覆盖旧记录。撤展完成只表示现场物件已核对，影像片段与资料归档还按各自流程处理，不能把所有后续步骤一起记作已完成。
