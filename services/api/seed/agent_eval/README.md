# 通用 Agent 任务集 v1

30 个手工编写的公开合成任务：计算 8、资料提取 8、约束规划 7、方案比较 7。
没有真实姓名、私人文档或外部服务。每轮独立运行，三种模式得到相同的任务输入与评分规则。
此任务集是起步基线，尚未采集真实模型成绩，也不能代表开放式通用任务的正确率。

`tasks.json` 保存输入、临时文本文件、可验证目标及必要工具；`fixtures.json` 保存合成模型的预设答案与工具请求。
`negative-fixtures.json` 的 calc-01 故意返回错误答案，用于证明评分会失败；需要同时指定 `--task calc-01`。
执行适配器只读取 fixture，不从评分规则补答案。fixture 只验证模型协议、编排、工具、账本和评分链路。
所有任务均只读；没有写入审批、知识库接入或真实模型调用。

| 类别 | 任务与验证方式 |
|---|---|
| calculation | 总价、折扣、税额、平均数、单位转换、增长率、并行轮数、剩余预算；数值容差与计算器成功结果 |
| extraction | 会议记录、版本更新、服务表格、优先级、缺失信息、时间边界、事故记录、去重；字段、集合、顺序、null 与文件引用 |
| planning | 评测、文档、活动、数据整理、发布、实验、交接；步骤完整性、先后依赖、工期上限、每阶段最少天数，允许其他合法分配 |
| comparison | 预算与延迟、持久性、加权评分、双项优劣、无可行方案、预算优先、平局规则；选择、约束值及文件引用 |

任务要求最终输出 JSON 对象，便于用代码检验目标，不用第二个模型打分。
这约束了输出格式；后续评估开放式表达质量需要独立评分标准及人工校准。

运行：`.venv\Scripts\python.exe -X utf8 scripts/eval_agent.py --offline`。
完整用法、记录格式、合成结果和限制见 [`docs/07-agent-evaluation.md`](../../../../docs/07-agent-evaluation.md)。
