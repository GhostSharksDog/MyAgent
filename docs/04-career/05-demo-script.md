# 三分钟演示：通用任务、过程与可靠性

目标岗位：AI 应用 / Agent 开发。演示使用公开文本，写权限保持关闭。
完整实测见 [可靠性证据](../05-reliability-evidence.md)；模型输出不是预写答案。
界面布局与公开合成截图见 [界面记录](../06-ui-design.md)，这些截图用于展示交互，不作为真实模型推理证据。

## 准备

1. 跑本地门禁、前端 `pnpm build`，启动 `scripts/dev.ps1 serve -NoReload`。
2. 在设置中确认通用能力集，并用 `/healthz` 确认服务就绪。知识库默认为空；文件场景只声明临时目录，
   放入公开 `sample.md`：`Public sample: batches contain 128 and 64 units.`。
3. 若现场网络不稳定，展示已保存的脱敏验证报告和离线回归。
   可以运行 `smoke_ui.py --visual` 验证三种尺寸下的真实页面如何消费合成 API/SSE，并明确说明这是界面检查。
4. 真实调用另设总请求额度；受限脚本每次输出最多 512 token、无自动重试，不修改 `.env`。
   本轮受限脚本 26 次，旧门禁失败预检另占用最多 4 次，30 次额度按已用尽处理。
   演示优先使用已保存证据和离线用例；继续真实调用需要用户另行授权额度。

## 0:00–0:45：任务与工具

展示 ReAct：输入“用 calculator 核验 `(128+64)*3`，说明使用了什么数据。”
有临时工作区时增加“读取 sample.md”；没有声明目录时文件工具不会出现。
展开「执行过程」中的工具卡片，指出真实参数、返回值、耗时与截断信息；结论应为 576。
首屏三个通用示例只填草稿；顶栏模型入口直接打开模型设置，工作区入口展示只读权限。

讲述：“我手写客户端与循环，这里能看到模型如何调用工具；默认不自动读取本机文件。”

## 0:45–1:30：三种编排

切换「先规划」「多专家」，展示输入区“本轮不使用会话历史”提示。
Plan 展示计划快照、步骤结论；Supervisor 展示资料分析员、方案分析员、结果核验员。
用已保存的正常运行报告说明三种模式都完成同一公开任务，比较请求数和 Usage，
不为了现场展示反复消耗额度。

讲述：“结构不同，但工具、配置与护栏共享。Plan 子任务只覆盖单步步数；其他配置继承。”

## 1:30–2:15：预算、取消与真实证据

展示 token_budget、timeout 与专家启动后取消的验证记录：
规划/路由达到阈值后不启动专家或汇总；超时使用整轮 deadline；取消后遗留专家任务为 0。
界面预算退出显示部分结果和原因，缺 Usage 显示统计不完整。
在合成 SSE 冒烟中点击停止，观察流确实取消、输入区恢复。
点击回答下的「查看运行摘要」或会话栏「运行记录」，展示停止轮次仍可查看、已知用量不冒充完整统计；筛选预算终止并打开一条旧摘要。说明记录只含结构化过程，原文不落记录，持久化须显式开启并重启。公开截图与限制见 [运行记录](../09-run-history.md)。

讲述：“已完成副作用不回滚；同步写入线程必须等待完成后释放互斥。
在途模型调用可能超额，所以我不把 token 阈值宣传成费用硬上限。”

## 2:15–3:00：复现与后续

可替换取消片段为文件批准演示：保持用户默认写权限不动，运行 `smoke_ui.py --visual` 的合成聊天入口，或展示[文件审批截图](../11-file-approvals.md)。指出完整差异、批准仅为核验中、applied 才成功，以及文件变化后需要新预览；实际写入证据来自临时工作区中的三种原内核回归。浏览器合成演示不执行写入、不调用模型。需要现场真实演示时另行准备临时工作区与明确模型额度，不复用已耗尽的30次额度。

运行公开消融：`eval_rag.py --compare --dataset general --diagnostics`。
展示60查询、k5，默认混合+重排正例Recall=.917、完整证据率=.875，多证据仍8/12；打开 `multi_evidence-01` 的缺失项，说明它已在召回并集第7位，但未进入最终top-5。`candidate_rank` 是重排前位置。无答案非空返回12/12不等于模型幻觉率，见 [最新复测](../10-rag-retrieval.md)。
展示离线测试和 Windows CI 配置；远端首跑尚待用户推送时应如实标明。
可运行 `eval_agent.py --offline`，打开 Markdown 报告和一个失败反例，说明它驱动实际三种编排和工具，
但模型输出是合成 fixture，90 轮通过证明执行／评分链路，不是模型任务成功率。NDCG 校正与记录格式见任务评测文档。

讲述：“我优先修配置丢失、取消泄漏、预算绕过这类能复现的问题。
下一步补独立测试集并验证多证据排序，再量真实 P95，标定生产时长与限流阈值。”
