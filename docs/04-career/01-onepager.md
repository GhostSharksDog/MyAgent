# Legacy · 通用 Agent 项目一页纸

面向 AI 应用 / Agent 开发岗位。Python 3.12 + FastAPI + React 19 + TypeScript。

**一句话：手写内核的通用 Agent，能根据用户明确提供的资料和权限调用工具，
以 ReAct、规划执行、多专家三种模式完成任务，并展示过程、预算终止与用量完整性。**

默认不加载私人语料、不启用写权限；求职是可选技能包，项目本身保持通用。

## 解决的问题

复杂任务经常需要多次模型/工具调用。只给最终答案时，用户难以判断资料来源、
调用消耗，以及点击停止后后台是否还在运行。本项目把计划、工具结果、专家结论、
停止原因和已知 Usage 放进同一事件流；中止轮次不会伪装成成功，也不进入成功会话历史。

## 三个可展开的工程点

1. **编排内核可解释。** 手写流式 tool_calls 分片重组、参数校验、工具错误回灌、
   并发与死循环护栏。三种模式共享单轮上下文；规划、重规划、路由、专家与汇总使用同一 deadline。
   子 Agent 复制完整配置，避免 profile/并发/上下文预算悄悄回到默认值。
2. **取消和成本有明确契约。** 停止后关闭流、取消并等待专家；共享注册表串行副作用，
   只读对照组仍并发。累计返回的 Usage 包括规划和失败子任务；缺失或中断明确标记不完整。
   token 阈值在调用边界执行，在途可超额，线程写入不回滚。
3. **结果能复现。** 默认离线测试、Windows CI、公开样本 RAG 消融和 Edge 冒烟。
   14 条公开查询、k=5：混合 Recall 0.869，对比 TF-IDF 0.821；特征重排 MRR 0.685，
   同时保留重排降低召回的负结果。

## 已取得的证据

- 当前 DeepSeek 上三种模式都完成临时公开文件读取与 `(128+64)*3=576` 核验。
- 受限真实验证累计 26 次 HTTP 尝试，最多 512 输出 token/次、无自动重试，不修改 `.env`；
  预算终止、超时和专家启动后的取消均有结果，取消后遗留专家任务为 0。
- Edge 已验证独立任务提示、预算终态、统计不完整与停止按钮；界面输入由合成 SSE 提供。
- 简约界面将计划／专家／工具整合为「执行过程」；预算、错误与裁剪提示不随折叠或隐藏统计消失。
  三尺寸的合成 API/SSE 截图用于展示界面交互，见 [界面验收](../06-ui-design.md)。
- 离线回归覆盖延迟、失败、共享互斥、预算隔离与真实 ASGI 断开；完整门禁数量见证据文件。
