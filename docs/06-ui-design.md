# Legacy 简约界面与验收记录

2026-10-06。本轮调整通用 Agent 的前端呈现，保留 Legacy 名称、现有 HTTP/SSE 协议、三种编排及文件权限边界。首屏以提问为中心，聊天中以答案为中心；工具、计划与专家仍可展开查看。

## 1. 设计系统与布局

所有界面颜色集中在 `apps/web/src/styles/tokens.css`。浅色使用暖白背景 `#F7F6F2`、白色面板、石墨正文 `#252923`、鼠尾草绿 `#557153` 与边框 `#E1E4DB`；发送按钮使用石墨色，绿色表达选中和运行状态。深色主题采用石墨背景，并单独调整文字、边框、强调色和提示色的对比度。

使用本机字体，不请求外部字体。正文 16px，辅助文字 12–14px，宽屏首屏标题 36px；输入框圆角 18px，普通面板圆角 12px。细边框、少量轻阴影和留白承担层级，不依靠密集徽标。

| 区域 | 实际布局 |
|---|---|
| 顶栏 | 56px；折叠会话栏、Legacy、当前模型、工具与设置。点击模型直接进入模型设置。 |
| 会话栏 | 桌面宽 240px；新建对话置顶，历史列表独立滚动，工作区与简短服务状态固定在底部。 |
| 对话 | 正文最大宽 760px；用户消息采用浅底气泡，助手答案使用正文排版。 |
| 文件栏 | 宽 320px；屏幕宽度 ≥1200px 时与聊天并列，较窄时作为侧面模态面板。 |
| 手机 | 宽度 ≤760px 时会话与文件均为抽屉，同一时间只打开一个。输入区保持可见，长路径和代码不能撑宽页面。 |

首屏展示“有什么需要一起解决？”，下方提供计算核验、整理文本、制定计划三个通用示例。示例只填入草稿并聚焦，不自动发送，也不依赖个人简历或私人文件。

应用始终保留同一个 Composer 实例：空对话时通过布局居中，有消息后停留在底部输入区域。切换呈现位置不重新挂载输入框，保留草稿、焦点、中文输入法组合状态与自适应高度。模式选择在左下，发送／停止在右下；支持 Enter 发送和 Ctrl/⌘+Enter 发送两种偏好。

## 2. 交互与真实状态

- **三种模式**：ReAct 可使用当前会话历史；Plan、Supervisor 明确标注“独立任务 · 本轮不使用会话历史”，输入中需提供背景。未选择会话时显示“不保存此次对话”，同时保留新建入口。
- **执行过程**：计划、专家和工具整合到一个可展开区域。运行时摘要显示当前动作和进度；不曾主动展开的过程完成后保持收起，用户主动展开后保持展开。工具参数、结果、失败和截断信息仍可查看。
- **终态**：预算终止、部分结果、错误、停止、上下文裁剪及用量不完整提示放在答案附近。收起执行过程或关闭“显示运行统计”都不会隐藏这些提示。停止按钮取消底层读取与 HTTP 连接。
- **五类设置**：通用外观与偏好立即生效、保存在浏览器；模型保存到清单后需点击“切换”启用；Agent 和工作区修改需保存此页；访问密钥有独立“保存到本浏览器”操作。写权限与敏感文件权限保持显眼，默认值和后端契约不变。
- **初始读取**：启动后读取当前设置，区分读取中、读取失败和确实未配置工作区。模型激活或配置保存成功后刷新模型、工具和服务状态。离线、未配置模型和缺访问密钥提供对应操作入口。
- **存储说明**：内存会话明确提示“重启后历史不会保留”；SQLite／PostgreSQL／Redis 标签依据服务返回的实际后端。工具面板把 API、执行步数、当前会话等技术信息放入“服务详情”。
- **文件请求**：切换工作区清除旧目录与预览；只接受最新目录／预览请求的响应，关闭面板后不提交迟到结果。浏览与 Agent 工具继续共用服务端权限边界。

模态设置、工具、文件和目录选择器统一使用焦点管理：打开后进入面板，Tab／Shift+Tab 在最上层模态内循环，Esc 关闭，关闭后返回可见的原触发控件。桌面并列文件栏不抢焦点、不限制 Tab；等待系统文件夹选择窗口时保留原有关闭保护。

主题继续使用 `legacy.theme` 存储键，保留已有 `light`、`dark`、`system` 偏好。首次访问、非法值或存储异常统一采用浅色；跟随系统时响应媒体查询变化。HTML 首屏同步脚本与 Hook 使用相同规则，实际同步脚本由 Node VM 回归执行，避免首次绘制后跳变。
