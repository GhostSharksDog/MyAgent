Legacy · Windows 10/11 x64

1. 解压整个 Legacy 文件夹，双击 Legacy.exe。不要只移动 exe 文件。
2. 浏览器自动打开；填写模型供应商、API 地址、模型名、API Key，点击“保存并开始使用”。保存不会测试模型或产生付费调用。
3. 新建对话后聊天。文件、终端和联网均为可选能力，在设置中自行启用。
4. 右下角托盘 Legacy 图标可打开界面或退出。关闭浏览器不会退出后台服务。

数据保存在 %LOCALAPPDATA%\Legacy，与程序目录分开。更新时替换程序文件夹即可，不要删除用户数据目录。
会话默认不过期，记忆必须经你确认才保存。设置 → 记忆与存储可查看、编辑、删除或关闭记忆。
设置 → MCP 可配置 Tavily（直接填 API Key）、Exa、本地文件和 Desktop Commander。本地服务需要你填写允许目录，默认不启动。
终端拥有当前 Windows 账户权限，目录不是终端沙箱。所有外部工具默认逐次确认。
联网和模型服务仍需要对应 API 或网络条件。暂不提供 OAuth 登录。

启动失败请查看 %LOCALAPPDATA%\Legacy\logs\legacy.log。不要删除数据库来尝试修复，先备份用户数据。
本包未签名；请核对提供的 SHA-256，Windows SmartScreen 可能提示未知发行者。
